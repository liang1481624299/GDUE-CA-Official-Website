## 项目简介

这是广东第二师范学院计算机协会的官方网站。网站采用现代简约的技术风格设计，支持简体中文、繁体中文、英语和日语四种语言。

## 核心功能

- **多语言支持**：4 种语言完整国际化
- **社团介绍**：历史时间线、组织架构、指导老师
- **项目展示**：社团项目作品展示与详情
- **活动管理**：活动记录与参与统计图表
- **招新报名**：在线表单提交
- **技术博客**：Markdown 文章渲染

## 技术栈

- **框架**：Next.js + React
- **UI**：Tailwind CSS + shadcn/ui + Radix UI
- **动画**：Framer Motion
- **图标**：Lucide
- **统计**：Umami
- **CDN**：Cloudflare
- **构建**：Turbopack
