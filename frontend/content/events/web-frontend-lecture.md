## 活动简介

本次讲座由技术部部长张三主讲，主题为"现代前端框架对比与实践"。讲座从 React、Vue、Svelte 三大框架的对比出发，深入探讨了前端开发的趋势。

## 讲座内容

- 主流前端框架横向对比
- React Hooks 最佳实践
- Vue 3 Composition API 详解
- 前端工程化与构建工具
- 现场答疑环节

共有 60 位同学参与，讲座后进行了热烈的讨论。
