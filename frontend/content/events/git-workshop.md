## 活动简介

Git 工作坊是为社团新成员准备的入门课程，帮助大家快速掌握 Git 版本控制工具的基本使用和团队协作流程。

## 工作坊内容

- Git 基础概念与安装配置
- 常用命令：add、commit、push、pull
- 分支管理与合并策略
- GitHub 协作流程（Fork & Pull Request）
- 解决冲突的最佳实践
- 实战练习：团队协作完成一个小项目

共有 35 位同学参与，大家完成了自己的第一次 Pull Request 提交。
